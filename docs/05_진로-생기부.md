# 5. 진로·생기부 연결 — 게임 프로그래밍 & 역량 어필

## 이 프로젝트가 증명하는 역량
대회가 "순위"가 아니라 "역량 관찰(생기부)" 성격이라면, 평가자가 보는 것은 다음 다섯 가지입니다. 이 프로젝트는 그 각각의 근거를 만들어 둡니다.

| 역량 | 이 프로젝트에서 드러나는 지점 |
|---|---|
| **탐구력** | 슬라이더로 변수를 바꿔 결과를 실험하고 원인을 해석 |
| **문제해결력** | 버그(진동·별칭·한글 렌더링 등)를 스스로 진단·수정한 과정 |
| **자기주도성** | 시키지 않아도 부품 라이브러리·17×2 데모·게임까지 확장 |
| **전공적합성** | 게임 AI(경로탐색·군집·FSM)를 사회문제에 응용 |
| **끈기** | 여러 각도로 반복 제작·개선하며 완성도를 끌어올림 |

## 게임 프로그래머 진로와의 직접 연결
우리가 만든 부품은 사실 **게임 AI의 4대 기둥** 그 자체입니다.

| 게임 AI 기둥 | 이 프로젝트의 부품/데모 |
|---|---|
| **경로탐색(Pathfinding)** | A\* — 대피(11)·도로망(9)·게임 |
| **행동결정(FSM)** | 유한상태기계 — 순찰·추격·도주 |
| **군집/조향(Steering)** | flocking·seek·flee·pursue — 해양 로봇·게임 물고기 |
| **절차적 생성(PCG)** | 절차적 배치·유전알고리즘·성장 나무 |

여기에 **플레이어 입력·게임 루프·점수 시스템**까지 더해, "관찰형 시뮬"을 실제 게임으로 완성했습니다.

## 생기부에 쓸 수 있는 문장 예시
> "게임 NPC의 핵심 기술인 A\* 경로탐색과 군집(Flocking) 행동, 유한상태기계를 직접 구현하고, 이를 재난 대피(SDG 11)·해양 정화(SDG 14) 등 사회문제 시뮬레이션에 응용함. 나아가 플레이어 입력과 점수 시스템을 결합해 실제 플레이 가능한 게임으로 발전시키며, 게임 AI 원리를 사회적 가치와 연결하는 통찰과 자기주도적 확장 역량을 보임."

## 탐구 서사(발표·자소서용) 3단 요약
1. **왜 궁금했나** — "게임 속 길찾기·무리 AI가 실제 사회문제에도 통할까?"
2. **어떻게 접근했나** — 재사용 부품을 쌓고, 변수를 바꿔가며 여러 SDG에 실험적으로 적용.
3. **무엇을 알게 됐나** — 단순한 규칙(경로탐색·군집·상태전이)만으로도 복잡한 사회현상과 게임 행동을 설명할 수 있음을 체득.
