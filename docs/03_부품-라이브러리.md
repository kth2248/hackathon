# 3. 부품 라이브러리 — 재사용 기능 모음

**생각의 출발점:** "모든 시뮬레이션은 결국 ① 계산하고 ② 화면에 그리고 ③ 사람이 조작한다." 이 셋을 부품으로 분리해 두면, 주제가 무엇이든 조립만으로 만들 수 있습니다.

처음엔 벡터수학·3D객체·UI 세 종류로 시작했고, 주제가 SDG·AI로 향하면서 **AI 기법 부품**을 대거 추가했습니다. 순수 계산 부품(아래 "순수" 표시)은 인터넷·화면 없이 자동 테스트로 검증돼 **믿고 쓸 수 있는 도구**입니다.

## 기능별 부품 (14개 카테고리)

| 카테고리 | 하는 일 | 종류 |
|---|---|---|
| **벡터 수학** | 방향·거리·회피·우회·혼합 계산 | 순수 |
| **3D 씬·객체** | 캔버스·에이전트·장애물·바닥·격자 그리기 | 화면 |
| **UI 위젯** | 값이 표시되는 슬라이더, 토글 스위치 | 화면 |
| **경로탐색(A\*)** | 격자에서 최단경로 찾기 — 게임 NPC 길찾기 | 순수 |
| **격자 세계** | 지도·장애물·좌표 변환 | 순수 |
| **조향·군집** | 목표 추적·도착·무리(flocking)·도주·추격 | 화면 |
| **최적화** | 유전알고리즘, 자원 배분 | 순수 |
| **자연어 파서** | 문장에서 색·모양·개수·패턴 추출 | 순수 |
| **시뮬 모델** | 전염병(SIR), 저수지 수급 | 순수 |
| **위험도** | 특정 위치가 얼마나 위험한지 점수화 | 순수 |
| **절차적 배치** | N개를 줄·나선·원·격자로 배치 | 순수 |
| **실시간 그래프** | 결과를 선·막대로 실시간 표시 | 화면 |
| **키보드 입력** | WASD·화살표로 플레이어 조작 | 화면 |
| **유한상태기계(FSM)** | 게임 AI 행동 전환(순찰·추격·도주) | 순수 |

## 왜 이렇게 정리했나
- **기능별 폴더** → 대회장에서 "이 기능 어디 있지?"를 즉시 찾으려고.
- **순수 부품 자동 검증(테스트 49개)** → 로직이 맞다는 보장을 미리 확보. 당일엔 조립만 신경 쓰면 됨.
- **AI 기법 부품 강조** → A\*·군집·유전알고리즘·자연어처리·FSM은 그대로 **AI 식견 + 게임 AI**를 증명하는 재료.
