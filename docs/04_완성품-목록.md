# 4. 완성품 목록 — 만든 데모 전부

모든 완성품은 부품을 조립한 것이며, 브라우저에서 3D로 실행되고 슬라이더로 실시간 조작됩니다.

## A. 초기 프로토타입 — "무해한 AI" 6종
주제("무한한 상상, 무해한 AI")를 여러 각도로 시각화하며 부품 조립을 실험한 결과물.

| 데모 | 내용 | 담은 메시지 |
|---|---|---|
| A 회피 | 장애물을 옆으로 우회해 목표로 가는 AI | 안전하게 판단하는 AI |
| D 신뢰도 | 여러 선택지 중 가장 안전한 것으로 판단을 옮김 | 판단 과정 자체를 보여줌 |
| E 협업 다리 | 사람이 목표를 정하면 AI가 안전 규칙 지키며 건설 | 인간-AI 공존 |
| F 성장 나무 | 안전 경계 안에서만 자라는 프랙탈 나무 | 무한한 상상 × 무해함 |
| B 자연어→3D | "빨간 구 5개를 나선으로" 말하면 3D 생성 | 상상을 말로 시각화 |
| 통합안 | 위 넷을 "상상→평가→행동→건설" 파이프라인으로 통합 | **알고도 무시하면 위험한 AI** |

## B. 전체 SDG 커버 — 17개 목표 × 2가지 각도 (총 34종)
"갑자기 특정 SDG 하나만 쓰라고 해도", "아예 다른 느낌으로 만들라고 해도" 대응하기 위해, **17개 SDG 각각을 서로 다른 2가지 장르**로 만들었습니다.

| SDG | 1차 (3D 에이전트 시뮬) | 2차 (다른 각도) |
|---|---|---|
| 1 빈곤 | 복지 자원 분배 | 소득 사다리·안전망 |
| 2 기아 | 유전알고리즘 작물 배치 | 영양 균형 대시보드 |
| 3 건강 | 전염병 확산(SIR) | 병상 수용력 |
| 4 교육 | 자연어→3D 학습도구 | 교육 접근성 지도 |
| 5 성평등 | 편향 vs 공정 승진 | 임금 격차 |
| 6 물 | 저수지 분배 | 상수도 공급망 |
| 7 에너지 | 발전소 최적 입지 | 발전 믹스(CO2 vs 비용) |
| 8 일자리 | 노동 배치·실업 | 스킬 매칭 |
| 9 인프라 | A\* 도로망 효율 | 네트워크 복원력 |
| 10 불평등 | 지니계수 재분배 | 계층 이동 사다리 |
| 11 도시 | A\* 재난 대피 | 교통 신호·혼잡 |
| 12 소비/생산 | 재활용 순환 | 순환경제 공급망 |
| 13 기후 | 탄소 vs 숲 흡수 | 해수면 상승 |
| 14 해양 | 군집 청소 로봇 | 먹이사슬(포식자-피식자) |
| 15 육상 | 유전알고리즘 숲 배치 | 삼림 파괴·재생 |
| 16 평화·제도 | 규칙→협력 창발 | 자원 분쟁·공정성 |
| 17 협력 | 국가 교환 네트워크 | 공동목표·무임승차 |

**왜 34개나?** 어떤 SDG가 어떤 스타일로 요구되든, 손에 쥔 목록에서 골라 바로 시작하기 위해. 완주 실패 위험을 0으로 만드는 안전장치.

## C. 공용 뼈대 (TEMPLATE_sdg_base)
34개를 다 외울 순 없습니다. 핵심 통찰은 **"거의 모든 SDG 시뮬 = 에이전트 + 격자맵 + 실시간 그래프"**. 이 3종 세트만 굳혀두고 ① 에이전트 행동 ② 그래프 지표 ③ 리셋 세 칸만 바꾸면 즉석 완성되는 템플릿. → 즉석 지정 대비의 90%.

## D. 게임 (GAME_ocean_cleanup)
진로가 게임 프로그래머라, "관찰형 시뮬"을 **진짜 플레이되는 게임**으로 올린 것.
- WASD로 청소 로봇 조작 → 제한시간 안에 플라스틱 수거
- 물고기는 다가가면 도망(도주 AI) / 점수·타이머·승패·재시작
- 게임 프로그래밍 3요소(입력·게임 상태/점수·적 AI)를 모두 구현.
