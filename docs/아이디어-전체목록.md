# 아이디어 전체 모음 — SDG 해커톤

> **읽는 분께**: 이건 부천 연합 해커톤(주제: **지속가능발전목표 SDGs**)을 준비하며 뽑은 **아이디어 후보 전부**입니다.
> 기술 설명은 뺐고 아이디어 자체만 정리했어요. **어느 게 임팩트 있는지, SDG 연결이 자연스러운지, 발표에 어울릴지** 봐주시면 됩니다.
>
> 대회는 순위 경쟁보다 **학생 역량을 보는(생기부) 성격**일 수 있고, 만든 사람의 진로는 **게임 프로그래머**입니다. 그 점을 감안해 피드백 주시면 특히 좋습니다.

---

## 1. 초기 아이디어 — "무해한 AI" 6종
(첫 주제였던 "무한한 상상, 무해한 AI" 때 뽑은 것들. SDG로도 재활용 가능.)

| 아이디어 | 컨셉 | 담은 메시지 |
|---|---|---|
| **회피하는 AI** | AI가 장애물(사람)을 옆으로 피해 목표로 감. 켜고 끄면 피함/돌진 | 안전하게 판단하는 AI |
| **판단하는 AI** | 여러 선택지 중 가장 안전한 쪽으로 판단을 옮기는 모습 | AI가 "왜" 무해한지, 과정을 보여줌 |
| **협업하는 AI** | 사람이 목표를 정하면 AI가 안전 규칙을 지키며 다리를 놓음 | 사람과 AI의 공존 |
| **성장하는 AI** | 안전 경계 안에서만 뻗어 나가는 나무 | 무한한 상상 × 무해함 |
| **말로 만드는 3D** | "빨간 공 5개를 나선으로" 말하면 그대로 3D 생성 | 상상을 말로 시각화 |
| **통합안** | 위 넷을 "상상→평가→행동→건설" 한 흐름으로 합침 | **AI는 위험을 몰라서가 아니라, 알고도 무시하면 위험해진다** |

## 2. SDG별 아이디어 — 17개 목표 × 서로 다른 2가지 각도 (총 34개)
"갑자기 특정 SDG 하나만 쓰라고 해도", "완전히 다른 느낌으로 만들라고 해도" 대응하려고 **목표마다 2가지 방향**으로 뽑았습니다.

| SDG | 각도 A | 각도 B |
|---|---|---|
| **1 빈곤 종식** | 복지 예산을 가난한 순으로 나눠 빈곤 가구 최소화 | 소득 사다리에서 추락하는 사람을 안전망이 받쳐줌 |
| **2 기아 종식** | 비옥한 땅을 AI가 찾아 작물을 최적 배치 | 예산을 식품군에 나눠 영양 균형 맞추기 |
| **3 건강** | 전염병 확산과 백신·거리두기 효과 | 감염자 수가 병상을 넘으면 의료붕괴 |
| **4 교육** | 말로 도형을 그리는 코딩 학습 도구 | 학교를 늘리면 통학권 밖 학생이 줄어듦 |
| **5 성평등** | 편향 vs 공정 승진에 따른 고위직 성비 | 정책으로 남녀 임금 격차 좁히기 |
| **6 깨끗한 물** | 가뭄 저수지를 농업·식수·공업에 분배 | 수원에서 파이프가 닿는 가구만 급수 |
| **7 에너지** | 발전소를 어디 지어야 도시를 다 덮나 | 태양광·풍력 비율로 CO2 vs 비용 균형 |
| **8 일자리** | 노동자를 산업에 배치, 실업률 관찰 | 직업훈련으로 스킬-일자리 매칭률 올리기 |
| **9 인프라** | 도로를 놓을수록 도시 간 이동이 빨라짐 | 링크가 끊겨도 도시망이 얼마나 버티나 |
| **10 불평등** | 부익부 vs 재분배의 격차(지니계수) | 사회 이동성이 높으면 아래에서도 올라감 |
| **11 도시** | 사람들이 스스로 최단 대피로를 찾음 | 신호 녹색시간으로 교차로 혼잡 줄이기 |
| **12 소비·생산** | 재활용률을 높이면 폐기물이 줄어듦 | 원료→생산→사용→폐기의 순환경제 점수 |
| **13 기후** | 탄소 배출 vs 숲 흡수로 기온 곡선 | 기온이 오르면 해수면이 상승해 땅이 잠김 |
| **14 해양** | 청소 로봇들이 협력해 플라스틱 수거 | 물고기-포식자 개체수와 오염의 영향 |
| **15 육상** | 나무를 넓게 퍼뜨리는 최적 배치 | 벌목 vs 재생 균형에 따른 숲 유지 |
| **16 평화·제도** | 규칙(제도)이 셀수록 협력이 늘어남 | 불공정한 자원 분배가 분쟁을 키움 |
| **17 지구촌 협력** | 나라들이 자원을 나누면 전체 번영↑ | 무임승차가 많으면 공동 목표가 늦어짐 |

> 공통적으로 모든 아이디어는 **슬라이더를 움직이면 결과(그래프)가 실시간으로 바뀌게** 만들어, "값을 바꿔 실험 → 결과 비교"가 보이도록 했습니다.

## 4. "즉석 지정" 대비 아이디어
대회장에서 SDG가 갑자기 정해질 경우를 대비해, **어떤 주제든 그 위에 얹기만 하면 되는 공용 틀**("에이전트 + 지도 + 실시간 그래프")도 준비해 뒀습니다. 목표 이름표만 바꾸면 새 아이디어로 변신합니다.

## 손봐주실 때 참고
- 어느 아이디어가 **가장 임팩트 있고 발표에서 눈길을 끌까요?**
- SDG 연결이 **억지스러운 것**은 없나요? (특히 1·5·8·10·16·17처럼 사회·제도 성격이 강한 것)
- 여러 SDG를 **하나로 묶는다면** 어떤 조합이 좋을까요?
- 게임 아이디어를 **메인으로 밀어도** 괜찮을까요, 아니면 시뮬레이션이 안전할까요?
