# ② 해양 청소 로봇 함대 — 설명서

> **역할: 메인(게임AI 어필).** 청소 로봇들이 무리 규칙으로 협력하며 쓰레기를 나눠 수거. **게임 AI(추적·군집·협력)를 정면으로 보여주는 카드.** 가장 최근에·가장 많이 손봐서 제일 익숙함 = 참고 없이 재현하기 좋음. SDG 14(해양) + 12(폐기물).

---

## 1. 이게 뭐 하는 프로그램인가 (한 문장)
여러 청소 로봇이 **명령 없이도 서로 협력**하며, 각자 다른 쓰레기를 맡아 쫓아가 수거하고, 장애물은 피한다.

## 2. 어떻게 작동하나 (게임 AI 개념 = 발표에서 이 용어를 그대로 쓸 것)
- **seek(추적):** 각 로봇이 가장 가까운 쓰레기로 향한다.
- **separation(분리):** 로봇끼리 너무 가까우면 밀어내 충돌을 피한다. (군집 flocking의 핵심)
- **작업 분담(task allocation):** 이미 다른 로봇이 맡은 쓰레기는 안 쫓는다 → 중복 없이 나눠 수거.
- **동적 타겟 추적:** 쓰레기가 조류에 떠다니므로 '움직이는 목표'를 쫓는다.
- **장애물 회피:** 배·부표에 가까워지면 밀려나며 우회.
- 로봇이 쓰레기에 닿으면 수거(사라짐). 다 치우면 리셋 반복. 하단 그래프 = 남은 쓰레기.

## 3. 조작 (슬라이더)
- **로봇 수** (1~12): 늘리면 수거가 빨라짐 → "협력의 효율" 탐구 포인트.
- **충돌 회피 범위**: 로봇끼리 벌어지는 간격 조절.

## 4. 쓰인 기술(부품)
- `steering.flock`(분리·정렬·응집), `steering.seek` — 군집·추적 AI
- `vpython_utils.make_scene`, `ui_widgets.make_labeled_slider`, `dataviz.make_line_curve`

## 5. 발표 포인트 (정확한 용어가 핵심)
- **소개:** "여러 청소 로봇이 명령 없이도 서로 협력해 바다를 치웁니다."
- **킬러 멘트:** *"명령하지 않았는데 협력이 나타납니다. 이게 '창발(emergence)'입니다."*
- **게임AI 연결(진로 어필):** *"이건 게임 NPC가 적을 쫓고(seek) 무리 짓는(flocking) 바로 그 기술이고, 저는 그걸 이 문제에 적용했습니다."*
- **탐구:** "로봇을 1대에서 5대로 늘리면 남은 쓰레기 곡선이 훨씬 빨리 떨어집니다."
- **정직한 동기:** "로봇한테 명령 안 해도 협력하게 만들 수 있을지 궁금했습니다."

## 6. 현장 재현 우선순위 (참고 없이 5시간 — 순서 엄수)
| 순위 | 기능 | 비고 |
|---|---|---|
| **① 반드시** | 로봇이 쓰레기 **seek해서 수거** | 이것만 돼도 절반 성공 |
| **② 반드시** | 로봇끼리 **충돌 회피(separation)** | "군집 AI"가 되는 지점 |
| **③ 반드시** | **슬라이더(로봇 수)** | 인터랙션 확보 |
| ④ 여유 되면 | **작업 분담**(중복 목표 방지) | 넣으면 "협력 AI"로 격 상승 |
| ⑤ 더 되면 | **조류에 떠다니는 쓰레기** | 예쁘지만 없어도 됨 |
| ⑥ 시간 없으면 버림 | **배·부표 장애물 회피** | 버그 위험 대비 효과 낮음 |

> **①②③이 90~120분 안에 되면 성공.** 나머지는 보너스. **기능을 더하려다 시간 잃지 말 것.**

## 7. 재현 핵심 로직(뼈대만 기억)
- 로봇 = 위치 + 속도. 매 프레임:
  1. 가장 가까운(아직 안 맡은) 쓰레기 = 목표 → **seek 방향**
  2. 주변 로봇에서 멀어지는 **분리 방향**
  3. `방향 = 목표*1.3 + 분리*0.5` → 정규화 → 속도만큼 이동
  4. 쓰레기와 거리 < 수거범위 → 수거
- 슬라이더 콜백에서 로봇 수 바꾸면 reset.

## 8. MVP 커트라인 (여기까지면 성공)
**로봇들이 쓰레기를 쫓아가 줍고, 서로 안 부딪히면 성공.** (작업분담·조류·장애물은 전부 보너스)
