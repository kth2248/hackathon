## 두 프로그램
1. [**CO2 vs 기온 데이터 비교**](1_CO2_소개.md) — 실제 데이터로 "CO2와 기온이 함께 오른다"를 확인 (SDG 13 기후)
2. [**바다 청소 로봇들 (무리 AI)**](2_청소로봇_소개.md) — 명령 없이 협력하는 로봇들이 해양 쓰레기 수거 (SDG 14 해양)

## 두 개를 한 줄로 엮으면
- **①은 데이터로 "문제가 진짜임"을 보여주고(믿게), ②는 기술로 "그래서 이렇게 해결해볼 수 있음"을 보여줍니다(느끼게).**
- 관통하는 생각: *"게임을 좋아하는 학생이, 그 기술이 진짜 세상 문제에도 통하는지 두 방향(데이터로 확인 · 기술로 적용)으로 알아본 것."*
