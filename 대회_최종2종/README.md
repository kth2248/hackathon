# 대회 최종 2종 — 생각과 연계 (중심 설명)

> 이 폴더는 대회 당일 만들 프로그램 **딱 2개**를 모은 곳.
> 각 폴더의 `설명.md`는 **기술이 아니라 "무슨 생각으로 만들었고, 어떤 관점이며, 무슨 효과가 있고, 둘이 어떻게 이어지는지"**를 중심으로 적었다. (기술·조작·재현 방법은 나중에 / 아직 완성형 아님)

## 두 프로그램
| 폴더 | 프로그램 | 한 마디로 |
|---|---|---|
| `1_CO2_데이터비교/` | CO2 vs 기온 추세 비교 | **사실을 "믿게" 한다** (실제 데이터·근거) |
| `2_해양청소로봇/` | 군집 청소 로봇 함대 | **해결을 "느끼게" 한다** (게임 AI·협력) |

## 하나로 꿰는 생각 (제일 중요)
- 이 두 개는 **따로 노는 두 작품이 아니라, 하나의 흐름**이다.
  1. ①이 **데이터로 "이 문제는 진짜입니다"** 못을 박고,
  2. ②가 **기술로 "그래서 이렇게 대응해볼 수 있습니다"**를 살아 움직이게 보여준다.
- **사실(①)이 감정(②)을 떠받치고, 감정이 다시 사실을 기억하게 만든다.**
- 두 개를 관통하는 진짜 동기는 하나다 — **"게임을 좋아하는 학생이, 그 기술이 진짜 세상 문제에도 통하는지 궁금해서 두 방향으로 확인해본 것."**
  - ①은 **데이터로 확인**, ②는 **기술로 적용**. 같은 호기심의 두 얼굴.

## 정직한 오프닝 (연기 없이)
> "저는 환경 운동가가 아니라 게임을 만들고 싶은 학생인데, 제가 좋아하는 게임 AI 기술이 진짜 문제에도 통할지 궁금해서 이걸 만들었습니다. 먼저 데이터로 문제가 진짜인지 확인하고(①), 그다음 기술로 어떻게 대응할 수 있는지 보여드리겠습니다(②)."
