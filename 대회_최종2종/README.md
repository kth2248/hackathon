# 대회 최종 2종 (현장 5시간 빌드용)

> 대회 당일 만들 프로그램 **딱 2개**만 모은 폴더. 나머지 45개는 연습 교재일 뿐, **이 2개가 실전.**

## 구성
| 폴더 | 프로그램 | 역할 | 실행 |
|---|---|---|---|
| `1_CO2_데이터비교/` | CO2 vs 기온 추세 비교 | **안전한 앵커** (주최 요구 데이터형 정면 부합) — 먼저 완성 | `python main.py` |
| `2_해양청소로봇/` | 군집 청소 로봇 함대 | **메인** (게임AI 추적·군집·협력) — 익숙해서 재현 안전 | `python main.py` |

각 폴더의 **`설명.md`**에 작동 원리·조작·발표 포인트·**현장 재현 순서·MVP 커트라인**이 다 있음.

## 왜 이 2개인가 (다시 안 흔들리기)
- ①은 **주최가 명시한 형식**에 정면으로 맞아 "요구 충족"을 보장하는 안전판.
- ②는 **가장 익숙하고** 게임AI(추적·협력)가 제일 풍부한 카드.
- 서로 안 겹치고 **"근거(①) + 기술력(②)"으로 완벽 보완.** 더 나은 조합 없음 → 확정.

## 대회 당일 순서 (5시간)
1. **0~90분:** ① 완성 (배열·두 선·상관계수) → 확실한 성과 1개 확보
2. **90~100분:** ① 켜보고 저장 (안전 체크포인트)
3. **100~230분:** ② (seek 수거 → 충돌회피 → 슬라이더, 여유 되면 작업분담)
4. **230~260분:** ② 버그 잡기
5. **260~300분:** 둘 다 점검 + 발표 리허설(각 30초)

> **신성한 규칙:** 90분에 ①이 안 끝나면 더 단순화해서라도 끝내고 ②로. **완성된 하나 > 미완성 둘.**

## 정직한 오프닝 한 문장 (연기 X)
> "저는 환경 운동가가 아니라 게임을 만들고 싶은 학생인데, 제가 좋아하는 게임 AI 기술이 진짜 문제에도 통할지 궁금해서 만들었습니다."
