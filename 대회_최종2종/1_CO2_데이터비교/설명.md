# ① CO2 vs 기온 데이터 비교 — 설명서

> **역할: 안전한 앵커.** 주최측이 명시한 "데이터 처리 → 결과물, SDG 연결, VPython" 형식에 **정면으로 맞는 카드.** 먼저 완성해서 확실한 성과 1개를 손에 쥐는 용도. SDG 13(기후).

---

## 1. 이게 뭐 하는 프로그램인가 (한 문장)
연도별 **CO2 농도**와 **지구 평균기온**, 두 실측 데이터를 한 화면에 겹쳐 그려 **"둘이 같이 오른다"**를 보여주고, **상관계수**로 그 관계를 숫자로 증명한다.

## 2. 어떻게 작동하나
- `co2_temp.csv`에서 연도·CO2(ppm)·기온이상치(℃)를 읽는다. (1960~2020, 실측 대표값 13개)
- 두 지표를 각각 0~100%로 **정규화**해 한 그래프에 겹쳐 그린다 → 두 선이 나란히 우상향.
- 별도 그래프에 **산점도**(X=CO2, Y=기온)를 찍는다 → 점들이 우상향 직선이면 상관 있음.
- **피어슨 상관계수**를 계산해 표시 (이 데이터는 **r ≈ 0.98**, 강한 양의 상관).
- 연도별로 점이 하나씩 찍히며 추세가 그려지는 연출.

## 3. 조작 / 화면
- 상단 캡션: 안내 문구 + 연도별 값
- 그래프 ①: 정규화 추세(빨강=CO2, 주황=기온)
- 그래프 ②: 산점도(파란 점)
- 끝나면: 상관계수 r + "상관 ≠ 인과" 경고 문구 표시

## 4. 쓰인 기술(부품)
- `stats.pearson` (상관계수), `stats.minmax_scale` (정규화) — 순수 함수, 자동 테스트됨
- VPython `graph` / `gcurve`(선) / `gdots`(산점도)
- `csv` 표준 모듈로 데이터 읽기

## 5. 발표 포인트 (그대로 말해도 됨)
- **관찰:** "CO2와 기온 두 선이 거의 똑같이 오릅니다 — 강한 양의 상관, r≈0.98입니다."
- **비판적 사고(핵심):** *"단, 상관이 곧 인과는 아닙니다. 그래서 배출 급증기와 기온 급등기가 실제로 맞물리는지도 확인했습니다."*
- **의미:** "이 데이터가 '탄소를 줄여야 한다'는 주장의 객관적 근거가 됩니다."
- **정직한 동기(오프닝):** "저는 환경 운동가가 아니라 게임을 만들고 싶은 학생인데, 데이터로 보면 진짜 CO2와 기온이 같이 오르는지 눈으로 확인해보고 싶었습니다."

## 6. 현장 재현 핵심 순서 (참고 없이 만들 때)
1. **데이터 배열 박기** — CSV를 못 보면 아래 값을 코드에 직접 리스트로. (제일 확실한 백업)
2. **두 선 그래프** — graph + gcurve 2개. 정규화(minmax)해서 같은 축에 겹치기.
3. **상관계수** — pearson 공식(평균 빼고 곱해서 더하고, 각자 제곱합 제곱근으로 나눔).
4. (여유) 산점도 gdots + "상관≠인과" 문구.

### 암기용 대표값 (연도, CO2 ppm, 기온이상치 ℃)

## 7. MVP 커트라인 (여기까지면 성공)
**두 선이 한 화면에 겹쳐 그려지고 "둘 다 우상향"이 보이면 성공.** (상관계수·산점도·연출은 보너스)
