# 바다 청소 게임 (GAME_ocean_cleanup)

> SDG 14 해양 + **게임 프로그래밍** 데모. 진짜 플레이되는 게임.

## 실행 & 조작
```powershell
cd products\GAME_ocean_cleanup
python main.py
```
1. 브라우저 창이 뜨면 **화면을 한 번 클릭**(키보드 포커스)
2. **WASD** 또는 **화살표키**로 노란 청소 로봇 이동
3. 제한시간(45초) 안에 **주황 플라스틱**을 최대한 수거
4. 물고기(청록)는 다가가면 **도망친다**
5. 시간 종료/전부 수거 시 결과 표시 → **"다시 시작"** 버튼

## 들어간 게임 프로그래밍 기술
| 요소 | 구현 | 부품 |
|---|---|---|
| **플레이어 입력** | WASD/화살표로 실시간 조작 | `input/keyboard.py` (Keyboard) |
| **적 AI (도주)** | 플레이어 근접 시 flee, 아니면 헤엄 | `steering.flee` |
| **게임 상태·점수·타이머** | 점수/남은시간/승패, 재시작 | 게임 루프 + HUD |
| **상태 전환(FSM)** | 순찰↔추격↔도주 패턴(부품 제공) | `gameai/fsm.py` |

## 확장 아이디어 (게임 프로그래밍 심화)
- 물고기에 **FSM** 적용: 순찰→(가까움)도주→(안전)순찰 상태 전환
- 장애물/암초 추가 후 **A\* 경로탐색**으로 회피
- 난이도(물고기 수·시간) 슬라이더, 최고점수 저장
- 마우스 클릭으로 그물 던지기(범위 수거)
