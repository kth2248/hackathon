# F안 — 안전 경계 안에서 자라는 성장 나무

> 난이도: **중간** / 주제 설명 용이성: **높음** / 시각적 임팩트: **최대** — 추천: 시간 여유 있을 때

## 개념
가지가 프랙탈처럼 계속 뻗어 나가되(**무한한 상상**), 투명한 **안전 경계 구**에 닿으려 하면 방향을 안쪽으로 꺾어 경계 밖으로 나가지 않는다(**무해함**). 경계 크기를 슬라이더로 조절하면 나무 형태가 실시간으로 달라진다.

## 핵심 로직
1. 가지 끝(tip)마다 성장 방향을 랜덤하게 살짝 흔들며 앞으로 자람.
2. 다음 위치가 안전 경계(반지름 R 구) 밖이면 → **원점 방향으로 방향을 꺾어** 경계 안에 머물게 함 (avoid 원리를 '경계'에 적용).
3. 일정 확률로 새 가지가 갈라짐(재귀적 성장), 동시 성장 tip은 `MAX_TIPS(40)`개로 제한.
4. **꺾인 순간의 가지는 빨강**(제약 작동), 평소는 초록.

## 성능 처리 (반영됨)
- cylinder가 무한 누적되면 발표 중 느려지므로, 가지 수가 `MAX_BRANCHES(1500)`를 넘으면 **오래된 가지부터 자동으로 숨김**(`visible=False`). → 몇 분 실행해도 부드럽게 유지.

## 재사용 부품
- `vpython_utils`: `make_scene`
- `ui_widgets`: `make_labeled_slider`
- (경계는 `sphere`, 가지는 `cylinder` 직접 사용)

## 조작 (발표 승부처)
- 슬라이더 **안전 경계 반지름**: 줄이면 나무가 작고 조밀하게, 늘리면 크게 자람 → "상상의 자유 = 경계가 정한다"를 실시간으로 시연.

## 테스트 방법
1. `python main.py` → 원점에서 나무가 위로 자라나는가
2. 가지가 투명 경계 구에 닿으면 **방향을 꺾어 안쪽으로** 계속 자라는가 (꺾이는 순간 빨강)
3. **경계 반지름** 슬라이더를 줄이면 작고 조밀하게, 늘리면 크게 자라는가
4. 몇 분 두어도 **느려지지 않는가**(오래된 가지 숨김이 동작)

## 확장 아이디어 (시간 남으면)
- 경계 안/밖 두 그루 비교(제약 있음 vs 없음 — 없는 쪽은 화면 밖으로 통제 불능)
- 성장 속도 슬라이더화
- 계절처럼 색이 변하는 연출
