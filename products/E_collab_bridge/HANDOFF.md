# E안 — 인간-AI 협업 다리 건설

> 난이도: **높음** (목표 지정 UI + 블록 생성 + 안전 제약) / 주제 설명 용이성: **중간**

## 개념
사람(파란 구)이 슬라이더로 **다리의 목표 지점(x)**을 지정하면, AI(초록 구)가 **안전 규칙**을 지키며 블록을 하나씩 놓아 다리를 완성한다. **사람이 방향을 정하고 AI가 안전하게 실행** → "AI와 미래의 공존"을 협업으로 형상화.

## 핵심 로직
1. 목표 지점 x를 슬라이더로 받음 → 파란 사람 마커가 그 지점을 가리킴.
2. AI는 `STEP_FRAMES(30)`마다 마지막 블록에서 목표 방향으로 **한 칸씩** 블록을 놓음(순차 건설).
3. 안전 규칙(ON): 블록 높이를 `MAX_HEIGHT` 이하로 제한 → **평평한 다리**(주황).
4. 안전 규칙(OFF): 높이 제한 없이 한 칸마다 위로 쌓음 → **불안정하게 올라가는 다리**(빨강).
5. 목표에 도달(간격 이내)하면 블록 생성이 멈춤.

## 재사용 부품
- `vpython_utils`: `make_scene`
- `ui_widgets`: `make_labeled_slider`(목표 지정), `make_toggle`(안전 규칙)
- (블록/마커는 이 시나리오 전용이라 `box`/`sphere` 직접 사용)

## 조작 (발표 승부처)
- 슬라이더 **목표 지점 x**: 사람이 다리를 어디까지 놓을지 지정 → 사람 마커가 이동, AI가 그쪽으로 건설
- 체크박스 **AI 안전 규칙**: OFF로 하면 규칙 없이 불안정하게 쌓이는 모습(빨강) → 규칙의 필요성을 대비로 보여줌

## 테스트 방법
1. `python main.py` → 창이 뜨고 파란(사람)·초록(AI) 구가 보이는가
2. **목표 지점** 슬라이더를 옮기면 파란 사람 마커가 따라 움직이는가
3. AI 초록 마커가 목표를 향해 **블록을 한 칸씩 순차적으로** 놓는가 (한 번에 다 X)
4. **안전 규칙 OFF** 시 블록이 점점 **위로 불안정하게(빨강)** 쌓이는가
5. 목표에 도달하면 블록 생성이 멈추는가

## 확장 아이디어 (시간 남으면)
- 불안정하게 쌓인 블록이 일정 개수 넘으면 무너지는 낙하 애니메이션
- 목표 지점 z축 슬라이더 추가(3D 확장)
- "리셋" 토글로 다리를 처음부터 다시 건설
