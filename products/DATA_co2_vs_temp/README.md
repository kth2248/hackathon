# CO2 vs 기온 추세 비교 (DATA_co2_vs_temp)

> **주최측 예시형 = 데이터 분석·추세 비교.** 3D 시뮬이 아니라 실제 데이터를 그래프로 비교한다. SDG 13(기후).

## 실행
```powershell
cd products\DATA_co2_vs_temp
python main.py
```
연도별로 점이 하나씩 찍히며 두 그래프가 그려진다.

## 무엇을 보여주나
- **그래프 ①**: 연도별 CO2(빨강)와 기온(주황)을 각각 0~100%로 정규화해 겹쳐 그림 → **두 선이 나란히 우상향**.
- **그래프 ②**: X=CO2, Y=기온 산점도 → 점들이 **우상향 직선**이면 강한 상관.
- **상관계수 r**: 자동 계산·표시(이 데이터는 **r ≈ 0.98**, 강한 양의 상관).

## 데이터
- `co2_temp.csv` — 1960~2020 실측 **대표값**(NOAA Mauna Loa CO2 + NASA GISTEMP 기온 이상치 추세 반영, 5년 간격 13점).
- **오프라인 안전**(인터넷 불필요). 실제 CSV를 구하면 같은 형식(`year,co2_ppm,temp_anomaly`)으로 교체만 하면 됨.

## 쓰인 부품
- `stats.pearson` (상관계수), `stats.minmax_scale` (정규화) — 순수 부품, 자동 테스트됨
- VPython `graph`/`gcurve`/`gdots` (선·산점도)

## 발표·탐구 어필 포인트
- **관찰:** "CO2와 기온 두 선이 거의 똑같이 오릅니다 — 강한 양의 상관(r≈0.98)."
- **비판적 사고(핵심):** "다만 상관이 곧 인과는 아닙니다. 그래서 배출 급증기와 기온 급등기가 맞물리는지도 확인했습니다."
- **의미:** "이 데이터가 '탄소를 줄여야 한다'는 주장의 객관적 근거가 됩니다."
- **생기부:** "공개 관측 데이터로 두 지표의 추세를 비교·분석하고, 상관과 인과를 구분하는 비판적 데이터 리터러시를 보임."
