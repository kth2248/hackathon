# 에코 타워디펜스 (GAME_eco_defense)

> **게임 + AI + SDG를 다 합친** 통합 게임. SDG 7·11·13(에너지·도시·기후).

## 실행 & 조작
```powershell
cd products\GAME_eco_defense
python main.py
```
1. 브라우저 창이 뜨면 **격자 칸을 마우스로 클릭** → 재생에너지 타워(청록) 설치
2. **오염 몬스터(빨강)**가 왼쪽 스폰에서 오른쪽 **기지(초록)**로 밀려온다
3. 타워는 사거리 안 몬스터를 **자동 조준**해 노란 빔으로 공격
4. 몬스터를 잡으면 **크레딧+점수**, 기지에 닿으면 **기지 체력↓** → 0이면 게임 오버
5. 웨이브가 갈수록 몬스터가 많아진다 / **"다시 시작"** 버튼

## 여기 들어간 게임 + AI 기술
| 요소 | 구현 |
|---|---|
| **적 AI (길찾기)** | 몬스터가 **A\* 경로탐색**으로 기지까지 옴. **타워를 세우면 스스로 우회**(재탐색) |
| **타워 AI (조준)** | 사거리 안 가장 가까운 적을 자동 타겟팅 |
| **게임 시스템** | 웨이브, 자원(크레딧) 경제, 기지 체력, 점수, 승패, 재시작 |
| **플레이어 입력** | 마우스 클릭으로 타워 배치 |

## SDG 연결
- 밀려오는 **오염**을 **재생에너지 타워**로 막아 도시를 지킨다 = 기후위기 대응(13)·지속가능 도시(11)·깨끗한 에너지(7)를 게임으로 체험.

## 핵심 재미 포인트(시연용)
- **타워로 길을 막으면 몬스터가 빙 둘러 우회**하는 장면 = A* 경로탐색 AI가 눈에 보이는 순간. "미로를 내가 설계한다"는 전략성.

## 확장 아이디어
