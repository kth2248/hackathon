# TEMPLATE_sdg_base — 공용 뼈대 (복사해서 주제별로 채우기)

> "에이전트 + 격자맵 + 실시간 그래프" 3종 세트. 어떤 SDG가 나와도 **이 뼈대를 복사**해서
> `main.py`의 ①②③ 표시 부분만 바꾸면 주제 시뮬이 된다. 지금 상태로도 실행됨(랜덤 워크).

## 실행
```powershell
cd products\TEMPLATE_sdg_base
python main.py
```
파란 에이전트들이 격자 위를 돌아다니고, 하단 그래프가 실시간으로 그려지면 뼈대 정상.

## 조립된 부품 (모두 parts/에서 가져옴)
| 부품 | 역할 |
|---|---|
| `scene/vpython_utils` | 씬·에이전트 생성 |
| `world/grid` | 격자 맵·장애물 |
| `scene/grid_render` | 격자를 3D로(바닥·장애물·칸좌표) |
| `ui/ui_widgets` | 속도 슬라이더·실행 토글 |
| `dataviz/live_graph` | 실시간 지표 그래프 |

## 채울 곳 3군데 (main.py의 ①②③)
| 표시 | 무엇을 채우나 | 주제별 예시 부품 |
|---|---|---|
| **①** | 에이전트를 어떻게 움직일지 | 대피/인프라 → `astar` · 해양 → `steering.flock` · 전염병 → `epidemic.infect_step` |
| **②** | 그래프에 무엇을 그릴지 | 대피=미탈출 인원 / 해양=남은 쓰레기 / 전염병=감염자 수 |
| **③** | 리셋·종료 조건(선택) | 목표 도달 시 초기화 후 반복 |

## SDG별 갈아끼우기 요령
- **최적화형(2·7·15)**: 에이전트 대신 `genetic_optimize`로 배치 탐색 → 결과를 격자에 그리고 ②에 개선 곡선.
- **자원배분형(1·6·10·12·17)**: 에이전트를 줄이고 `allocate` + `resource`로 값 계산 → ②에 지표(만족도·지니계수) 그래프.
- **경로형(9·11)**: ①에서 `astar`로 각 에이전트 경로 계산 후 따라가게.
- **군집형(14·16)**: ①에서 `steering.flock`으로 이동 방향 결정.
