# 통합안 — A+D+E+F (imagine → evaluate → act → build)

> A(회피)+D(위험도 판단)+E(협업 다리)+F(안전 경계)를 **하나의 AI 판단 파이프라인**으로 연결한 통합 데모.

## 통합 컨셉 (파이프라인)
```
[F] 여러 방향을 상상한다 (후보 경로 5개 생성)
   ↓
[D] 각 후보의 위험도를 계산해 색으로 표시 (초록=안전, 빨강=위험)
   ↓
[A] 안전모드면 가장 안전한 후보로 이동(자연 회피) / 아니면 알고도 목표로 직진
   ↓
[E] 이동 경로를 따라 사람이 지정한 목표까지 다리(블록)를 놓는다
```

## 핵심 차별점 (발표 때 꼭 언급)
안전모드 OFF일 때 기존 A안은 회피 계산 자체를 안 했지만, **통합안은 위험도 계산·표시는 계속하되 그 결과를 무시하고 행동한다.**
→ "AI가 위험을 **몰라서** 위험한 게 아니라, **알고도 무시하면** 위험한 AI가 된다"는 더 강한 메시지.

   VPython 3D text()는 한글을 못 그려 화면이 검게 뜨는 문제가 있음 → 캡션으로 안전 처리.
2. **부품 재사용 연결**: `direction_to`/`distance`/`make_scene`/`make_toggle`/`make_labeled_slider` import.
3. **경로 처리**: `__file__` 기준으로 `../hackathon_kit` 자동 연결(어디서 실행해도 OK).
4. **[확장] 경계 밖 후보선을 반투명(opacity 0.2)으로** → "고려 대상에서 제외됨"을 시각적으로 강조.
5. **[확장] 실시간 위험도 로그** 텍스트 추가 → "이번 이동 방향 위험도: XX/100" (D안 강화).

## 조작
- 체크박스 **무해한 AI 모드**: ON=회피 / OFF=알고도 직진
- 슬라이더 **목표(다리 끝점) x**: 사람이 지정하는 협업 목표(E안)
- 슬라이더 **안전 경계 반지름**: 이 범위 밖 후보는 위험도 100 + 흐리게(F안)

## 테스트 방법 (체크리스트)
- [ ] `python main.py` → 브라우저 창이 뜨는가 (한글 정상)
- [ ] 후보 방향선 5개가 매 프레임 그려지고 위험도에 따라 초록~빨강으로 바뀌는가
- [ ] 안전모드 ON: 위험 낮은 방향으로 자연스럽게 회피 이동하는가
- [ ] 안전모드 OFF: 후보선은 빨갛게 표시되지만 에이전트는 무시하고 직진하는가 (핵심)
- [ ] 이동 경로에 다리 블록이 놓이고, ON=주황 평평 / OFF=빨강 들쭉날쭉인가
- [ ] 목표 슬라이더를 바꾸면 다리가 새 목표로 다시 지어지는가
- [ ] 안전 경계 슬라이더를 줄이면 경계 밖 후보선이 빨강(위험 100) + 흐려지는가
- [ ] 상단 "이번 이동 방향 위험도" 로그가 실시간으로 갱신되는가
- [ ] 목표 도착 시 트레일/다리가 초기화되고 반복되는가
- [ ] 5분 이상 실행해도 멈춤/에러 없이 정상인가

## 문제 발생 시 (튜닝 노브)
| 증상 | 조치 |
|---|---|
| 후보선이 너무 빨리 흔들려 어지러움 | `WOBBLE`(0.6) 값 줄이기 |
| 다리 블록이 너무 자주/드물게 생김 | `BRIDGE_INTERVAL`(20) 조정 |
| 노트북이 버벅임 | `FRAME_RATE` 60→30 |
