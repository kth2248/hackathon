# D안 — AI 신뢰도(안전 판단) 시각화

> 난이도: **낮음** / 주제 설명 용이성: **높음** / 추천: 시간이 부족할 때(안전)

## 개념
중심의 "AI 판단" 구 주위를 여러 선택지 입자가 공전한다. 각 입자는 안전 점수(0~1)를 가지며 색이 초록(안전)~빨강(위험)으로 바뀐다. AI는 매 순간 **가장 안전한 선택지로 연결선(시선)을 옮긴다.** "무해한 AI"를 결과가 아니라 **판단 과정 자체**로 보여준다.

## 핵심 로직
1. 입자 6개가 원을 그리며 공전.
2. 각 입자의 안전 점수는 **고정 기준값(base) 주위로 sin 진동** → "AI가 계속 재평가하는" 느낌 (극단으로 쏠리지 않음).
3. 색 = `vector(1-점수, 점수, 0)` (빨강~초록).
4. **안전 기준선**(슬라이더) 미만인 입자는 흐려지고 후보에서 제외.
5. 기준을 넘는 것 중 점수가 가장 높은 입자로 노란 연결선을 갱신. 아무도 기준을 못 넘으면 연결선을 끊고 **"판단 보류 ⚠️"**.

## 재사용 부품
- `vpython_utils`: `make_scene`
- `ui_widgets`: `make_labeled_slider`
- (입자/연결선은 이 시나리오 전용이라 `sphere`/`cylinder` 직접 사용)

## 조작 (발표 승부처)
- 슬라이더 **안전 기준선**: 올리면 위험한 선택지가 후보에서 빠짐(더 엄격 = 더 무해). 너무 높이면 "판단 보류"가 뜸 → AI가 무리하지 않고 멈추는 안전한 태도를 보여줌.

## 테스트 방법
1. `python main.py` → 창이 뜨고 중심 흰 구 + 공전하는 입자 6개가 보이는가
2. 입자 색이 초록~빨강으로 **시간에 따라 흔들리는가**
3. 노란 연결선이 매 순간 **가장 안전한(초록) 입자로 자동으로 옮겨가는가**
4. **안전 기준선** 슬라이더를 올리면 → 낮은 점수 입자가 **흐려지고** 후보에서 빠지는가
5. 기준선을 아주 높이면(예: 0.95) → "판단 보류 ⚠️"가 뜨고 연결선이 사라지는가

## 확장 아이디어 (시간 남으면)
- 입자 개수를 슬라이더로 조절
- 연결선이 바뀔 때 잠깐 반짝이는 효과
- 흔들림 속도(WOBBLE_SPEED) 슬라이더화
